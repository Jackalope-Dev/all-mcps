# Server-Side Upvote Dedup Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the client-only (`localStorage`) dedup on listing upvotes with a real server-side check, so the same visitor can't inflate a listing's upvote count by clearing storage, using a private window, or calling the API directly.

**Architecture:** A new D1 table (`upvote_records`) stores one row per `(server_id, salted-hash-of-IP)` pair. The existing `POST /api/mcp/[id]/metric` route inserts into it before incrementing `upvotes`, using SQLite's unique-constraint conflict handling for atomicity; a new `GET` on the same route lets the client check "has this visitor already voted" without forcing the listing detail page into dynamic rendering. No new cookie is introduced.

**Tech Stack:** Next.js route handlers (edge runtime) on Cloudflare Workers via OpenNext, D1 via Drizzle ORM, Web Crypto (`crypto.subtle`) for hashing.

## Global Constraints

- Dedup mechanism is hashed-IP only — no new cookie. (Reason: existing privacy copy states the public site sets no cookies for ordinary visitors; see spec.)
- Storage is D1 only — no KV namespace exists in `wrangler.jsonc` and none should be added for this feature.
- Hash formula: `SHA-256(ip + ":" + serverId + ":" + pepper)`, where `pepper` comes from `process.env.UPVOTE_HASH_SECRET` (a Wrangler secret, never added to the `vars` block in `wrangler.jsonc`).
- Client IP is read as `CF-Connecting-IP` first, falling back to the first entry of `X-Forwarded-For`, falling back to `127.0.0.1` (so local/dev requests without either header don't crash).
- Only the `"upvote"` metric is deduped. `"view"` and `"copy"` are unchanged.
- No retention/cleanup job for `upvote_records` in this plan (accepted tradeoff, see spec).
- This repo has no test runner configured (no vitest/jest, no `test` script). Do not add one as part of this plan — that's a separate decision. Verification steps below use `wrangler d1 execute --local` and `curl` against a local preview server instead of automated tests.
- Applying the D1 migration to the **production** database (`wrangler d1 migrations apply all-mcps --remote`) and setting the **production** `UPVOTE_HASH_SECRET` (`wrangler secret put UPVOTE_HASH_SECRET`) are NOT steps in this plan — they touch shared/production state and should be run by the project owner when ready to deploy, not automatically by whoever executes this plan.
- Spec: `docs/superpowers/specs/2026-07-27-upvote-dedup-design.md` (includes one revision made during planning — the UI dedup-status check moved from a server-component prop to a client-side fetch, to avoid forcing `app/mcp/[id]/page.tsx` into dynamic rendering; see that doc's "UI change" section for the reasoning).

- [ ] **Step 1: Create the hashing utility**

Create `lib/upvoteHash.ts`:

```ts
/**
 * Client-IP based dedup for the upvote metric — not tied to any account or
 * cookie. See docs/superpowers/specs/2026-07-27-upvote-dedup-design.md.
 */

export function getClientIp(req: Request): string {
  const cfIp = req.headers.get('cf-connecting-ip');
  if (cfIp) return cfIp;

  const forwardedFor = req.headers.get('x-forwarded-for');
  if (forwardedFor) return forwardedFor.split(',')[0].trim();

  return '127.0.0.1';
}

/**
 * One-way, salted hash of (ip, serverId). Returns null if the server-only
 * pepper isn't configured, so callers can fail closed instead of silently
 * hashing without a secret.
 */
export async function hashUpvoteVoter(ip: string, serverId: string): Promise<string | null> {
  const pepper = process.env.UPVOTE_HASH_SECRET;
  if (!pepper) return null;

  const digest = await crypto.subtle.digest(
    'SHA-256',
    new TextEncoder().encode(`${ip}:${serverId}:${pepper}`)
  );

  return Array.from(new Uint8Array(digest))
    .map((b) => b.toString(16).padStart(2, '0'))
    .join('');
}
```

- [ ] **Step 2: Rewrite the metric route**

Replace the full contents of `app/api/mcp/[id]/metric/route.ts` with:

```ts
import { NextResponse } from 'next/server';
import { getCloudflareContext } from '@opennextjs/cloudflare';
import { drizzle } from 'drizzle-orm/d1';
import { servers, upvoteRecords } from '../../../../../db/schema';
import { eq, sql, and } from 'drizzle-orm';
import { z } from 'zod';
import { getClientIp, hashUpvoteVoter } from '../../../../../lib/upvoteHash';

const metricSchema = z.object({
  metric: z.enum(["view", "copy", "upvote"])
});

export const runtime = 'edge';

async function getDb() {
  const ctx = await getCloudflareContext();
  const env = ctx.env;
  if (!env || !(env as any).DB) {
    return null;
  }
  return drizzle((env as any).DB as any);
}

export async function POST(req: Request, { params }: { params: Promise<{ id: string }> }) {
  try {
    const { id } = await params;
    const body = await req.json();
    const result = metricSchema.safeParse(body);

    if (!result.success) {
      return NextResponse.json({ error: result.error.issues }, { status: 400 });
    }

    const { metric } = result.data;

    let db;
    try {
      db = await getDb();
    } catch (e) {
      return NextResponse.json({ error: "Could not get Cloudflare context." }, { status: 500 });
    }
    if (!db) {
      return NextResponse.json({ error: "Database binding not found" }, { status: 500 });
    }

    if (metric === "upvote") {
      const ip = getClientIp(req);
      const ipHash = await hashUpvoteVoter(ip, id);
      if (!ipHash) {
        return NextResponse.json({ error: "Upvote is not configured" }, { status: 500 });
      }

      const inserted = await db.insert(upvoteRecords)
        .values({ serverId: id, ipHash })
        .onConflictDoNothing({ target: [upvoteRecords.serverId, upvoteRecords.ipHash] })
        .returning({ serverId: upvoteRecords.serverId });

      if (inserted.length === 0) {
        return NextResponse.json({ success: false, alreadyVoted: true }, { status: 409 });
      }

      await db.update(servers)
        .set({ upvotes: sql`${servers.upvotes} + 1` })
        .where(eq(servers.id, id));

      return NextResponse.json({ success: true });
    }

    const updateQuery = metric === "view"
      ? { views: sql`${servers.views} + 1` }
      : { copies: sql`${servers.copies} + 1` };

    await db.update(servers).set(updateQuery).where(eq(servers.id, id));
    return NextResponse.json({ success: true });
  } catch (error) {
    console.error("Metric update error:", error);
    return NextResponse.json({ error: "Internal Server Error" }, { status: 500 });
  }
}

export async function GET(req: Request, { params }: { params: Promise<{ id: string }> }) {
  try {
    const { id } = await params;

    let db;
    try {
      db = await getDb();
    } catch (e) {
      return NextResponse.json({ error: "Could not get Cloudflare context." }, { status: 500 });
    }
    if (!db) {
      return NextResponse.json({ error: "Database binding not found" }, { status: 500 });
    }

    const ip = getClientIp(req);
    const ipHash = await hashUpvoteVoter(ip, id);
    if (!ipHash) {
      return NextResponse.json({ alreadyVoted: false });
    }

    const existing = await db.select({ serverId: upvoteRecords.serverId })
      .from(upvoteRecords)
      .where(and(eq(upvoteRecords.serverId, id), eq(upvoteRecords.ipHash, ipHash)))
      .limit(1);

    return NextResponse.json({ alreadyVoted: existing.length > 0 });
  } catch (error) {
    console.error("Metric status error:", error);
    return NextResponse.json({ error: "Internal Server Error" }, { status: 500 });
  }
}
```

Note: this factors the repeated "get context, check `env.DB`" block from the original file into a shared `getDb()` helper used by both `POST` and `GET` — the original only had `POST`, so there was no duplication to notice before now.

- [ ] **Step 1: Update the component**

Replace the full contents of `components/ui/UpvoteButton.tsx` with:

```tsx
'use client';

import React, { useState, useEffect } from 'react';
import { Heart } from 'lucide-react';

export function UpvoteButton({ serverId, initialCount }: { serverId: string; initialCount: number }) {
  const [upvotes, setUpvotes] = useState(initialCount || 0);
  const [hasUpvoted, setHasUpvoted] = useState(false);
  const [isHovered, setIsHovered] = useState(false);

  useEffect(() => {
    const upvoted = localStorage.getItem(`upvote_${serverId}`);
    if (upvoted) {
      setHasUpvoted(true);
      return;
    }

    let cancelled = false;

    fetch(`/api/mcp/${serverId}/metric`)
      .then((res) => (res.ok ? res.json() : null))
      .then((data) => {
        if (!cancelled && data?.alreadyVoted) {
          setHasUpvoted(true);
          localStorage.setItem(`upvote_${serverId}`, 'true');
        }
      })
      .catch(() => {
        // Best-effort convenience check; leaving the button clickable on
        // failure is fine — the POST below still enforces dedup server-side.
      });

    return () => {
      cancelled = true;
    };
  }, [serverId]);

  const handleUpvote = async () => {
    if (hasUpvoted) return;

    // Optimistic UI update
    setUpvotes(prev => prev + 1);
    setHasUpvoted(true);
    localStorage.setItem(`upvote_${serverId}`, 'true');

    try {
      const res = await fetch(`/api/mcp/${serverId}/metric`, {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ metric: 'upvote' }),
      });

      if (res.status === 409) {
        // Already voted server-side (e.g. a stale/cleared localStorage flag).
        // Keep hasUpvoted true, but undo the optimistic +1 since this click
        // didn't register a new vote.
        setUpvotes(prev => prev - 1);
        return;
      }

      if (!res.ok) {
        throw new Error(`Upvote request failed with status ${res.status}`);
      }
    } catch (e) {
      console.error("Failed to upvote:", e);
      // Revert on failure
      setUpvotes(prev => prev - 1);
      setHasUpvoted(false);
      localStorage.removeItem(`upvote_${serverId}`);
    }
  };

  return (
    <button
      onClick={handleUpvote}
      onMouseEnter={() => setIsHovered(true)}
      onMouseLeave={() => setIsHovered(false)}
      disabled={hasUpvoted}
      style={{
        display: 'flex',
        alignItems: 'center',
        gap: '0.5rem',
        background: hasUpvoted ? 'rgba(236, 72, 153, 0.15)' : 'rgba(255, 255, 255, 0.05)',
        border: `1px solid ${hasUpvoted ? 'rgba(236, 72, 153, 0.3)' : 'rgba(255, 255, 255, 0.1)'}`,
        borderRadius: '100px',
        padding: '0.5rem 1rem',
        color: hasUpvoted ? '#ec4899' : (isHovered ? 'white' : 'var(--text-secondary)'),
        fontSize: '0.875rem',
        fontWeight: hasUpvoted ? 600 : 500,
        cursor: hasUpvoted ? 'default' : 'pointer',
        transition: 'all 0.2s ease',
        boxShadow: hasUpvoted ? '0 0 10px rgba(236, 72, 153, 0.2)' : 'none',
      }}
    >
      <Heart
        size={16}
        fill={hasUpvoted ? '#ec4899' : (isHovered ? 'rgba(255,255,255,0.2)' : 'transparent')}
        color={hasUpvoted ? '#ec4899' : 'currentColor'}
        style={{ transition: 'all 0.2s ease' }}
      />
      {upvotes} {upvotes === 1 ? 'Upvote' : 'Upvotes'}
    </button>
  );
}
```

(Only the `useEffect` and the body of `handleUpvote` changed from the original; the JSX return block is unchanged.)
