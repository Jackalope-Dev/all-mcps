# Listing Logo Upload Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let claimed listing owners upload a logo from the dashboard; the server validates and re-encodes it, mirrors it in R2, queues it for admin approval, and once approved it renders on directory cards in place of the generated gradient avatar.

**Architecture:** A new `LOGOS` R2 bucket stores two objects per listing: `pending/<id>.png` (awaiting review) and `live/<id>.png` (approved, publicly served). Two new `servers` columns track this: `pendingLogoKey` (set while awaiting review) and `logoUrl` (set once approved). The upload route validates/resizes/re-encodes with `jimp` (already a dependency) before ever touching R2. Admin approval promotes the pending object to the live key; nothing uploaded is ever public before that. A thin route handler serves `live/<id>.png` at a stable `/logos/<id>` URL.

**Tech Stack:** Next.js route handlers on Cloudflare Workers (OpenNext), D1 via Drizzle ORM, Cloudflare R2, `jimp` for image decode/resize/re-encode.

## Global Constraints

- **No test runner in this repo** (no vitest/jest, no `test` script in `package.json`). Do not add one as part of this plan. Verification steps below use `wrangler d1 execute --local`, `npx tsc` (type-checking only, via the existing `noEmit: true` config), `curl` against a local preview server, and manual dashboard/admin clicks — matching how every other route in this codebase (claim, edit, admin actions) is verified today.
- **Accepted logo formats: PNG and JPEG only** — not WebP as the design doc listed. `jimp@0.22.12` (already a dependency, pure JS, no native bindings — a good fit for the Workers runtime) has no WebP decoder (`@jimp/webp` doesn't exist among its plugins; only `@jimp/png`, `@jimp/jpeg`, `@jimp/bmp`, `@jimp/gif`, `@jimp/tiff` do). Adding a second image library just to cover WebP isn't worth it for a directory-listing icon. This is a deliberate deviation from `docs/superpowers/specs/2026-07-28-listing-logo-upload-design.md`.
- **Rendering scope is `ServerIcon` in `components/DirectoryGrid.tsx` only** (grid + list card views) — the one place a per-listing gradient avatar exists in the app today. The listing detail page (`app/mcp/[id]/page.tsx`) and the OG image generators render no per-listing icon at all currently, so adding one there is new UI surface beyond what was reviewed and is out of scope for this plan.
- Max upload size: 5MB, checked via `file.size` before the bytes are ever read into memory.
- Output is always a 256×256 PNG (via Jimp's `.cover(256, 256)`) regardless of input format/dimensions — cropped-to-fill, not letterboxed.
- R2 binding name: `LOGOS`; bucket name: `all-mcps-logos`. **Creating the actual remote bucket (`wrangler r2 bucket create all-mcps-logos`) and any production deploy are NOT steps in this plan** — they touch shared/production infrastructure and should be run by the project owner when ready to ship. Local dev/preview uses Miniflare's simulated R2 and needs no remote bucket to exist.
- `npm run cf-typegen` (regenerates `cloudflare-env.d.ts` from `wrangler.jsonc`) needs Cloudflare auth. If it can't run in a given environment, that's fine — every existing route in this codebase reads `ctx.env` via an `any` cast rather than the generated type, and this plan's new routes do the same, so exact `R2Bucket` typing isn't load-bearing.
- Spec: `docs/superpowers/specs/2026-07-28-listing-logo-upload-design.md`.

- Produces: `export class LogoValidationError extends Error {}` and `export async function processLogoUpload(bytes: ArrayBuffer): Promise<Buffer>` — resolves to a 256×256 PNG buffer on success; rejects with `LogoValidationError` (safe to show the user) for bad input, or a generic `Error` for unexpected decode failures. Consumed by Task 3's upload route.

- [ ] **Step 1: Write the module**

Create `lib/logoImage.ts`:

```ts
import Jimp from 'jimp';

export class LogoValidationError extends Error {}

const MAX_BYTES = 5 * 1024 * 1024;
const OUTPUT_SIZE = 256;
const MIN_SOURCE_DIMENSION = 32;

const PNG_SIGNATURE = [0x89, 0x50, 0x4e, 0x47, 0x0d, 0x0a, 0x1a, 0x0a];
const JPEG_SIGNATURE = [0xff, 0xd8, 0xff];

function matchesSignature(bytes: Uint8Array, signature: number[]): boolean {
  if (bytes.length < signature.length) return false;
  return signature.every((byte, i) => bytes[i] === byte);
}

function isPngOrJpeg(bytes: Uint8Array): boolean {
  return matchesSignature(bytes, PNG_SIGNATURE) || matchesSignature(bytes, JPEG_SIGNATURE);
}

/**
 * Validates, decodes, and re-encodes an uploaded logo. Re-encoding (not just
 * passing the original bytes through) is what strips embedded
 * metadata/payloads — the decode step alone isn't enough.
 */
export async function processLogoUpload(bytes: ArrayBuffer): Promise<Buffer> {
  if (bytes.byteLength === 0) {
    throw new LogoValidationError('Uploaded file is empty.');
  }
  if (bytes.byteLength > MAX_BYTES) {
    throw new LogoValidationError('Logo must be 5MB or smaller.');
  }

  const view = new Uint8Array(bytes);
  if (!isPngOrJpeg(view)) {
    throw new LogoValidationError('Logo must be a PNG or JPEG image.');
  }

  let image: Jimp;
  try {
    image = await Jimp.read(Buffer.from(bytes));
  } catch {
    throw new LogoValidationError('Could not read this file as an image.');
  }

  if (image.bitmap.width < MIN_SOURCE_DIMENSION || image.bitmap.height < MIN_SOURCE_DIMENSION) {
    throw new LogoValidationError(`Image must be at least ${MIN_SOURCE_DIMENSION}x${MIN_SOURCE_DIMENSION}px.`);
  }

  image.cover(OUTPUT_SIZE, OUTPUT_SIZE);
  return image.getBufferAsync(Jimp.MIME_PNG);
}
```

```ts
import { NextResponse } from 'next/server';
import { getCloudflareContext } from '@opennextjs/cloudflare';
import { drizzle } from 'drizzle-orm/d1';
import { eq } from 'drizzle-orm';
import { servers } from '@/db/schema';
import { auth } from '@/lib/auth';
import { processLogoUpload, LogoValidationError } from '@/lib/logoImage';
import { sendNotificationEmail, getEmailEnv } from '@/lib/notify';
import { getAppUrl } from '@/lib/stripe';

const ID_PATTERN = /^[a-z0-9-]+$/;

export async function POST(req: Request) {
  try {
    const session = await auth();
    const userId = session?.user?.id;
    if (!userId) {
      return NextResponse.json({ error: 'Sign in required.' }, { status: 401 });
    }

    const form = await req.formData();
    const id = String(form.get('id') || '');
    const file = form.get('logo');

    if (!id || !ID_PATTERN.test(id)) {
      return NextResponse.json({ error: 'Invalid listing id.' }, { status: 400 });
    }
    if (!(file instanceof File)) {
      return NextResponse.json({ error: 'No logo file provided.' }, { status: 400 });
    }

    let env: any;
    try {
      const ctx = await getCloudflareContext();
      env = ctx.env;
    } catch {
      return NextResponse.json({ error: 'Storage unavailable' }, { status: 500 });
    }
    if (!env?.DB || !env?.LOGOS) {
      return NextResponse.json({ error: 'Storage unavailable' }, { status: 500 });
    }

    const db = drizzle(env.DB as any);
    const rows = await db.select().from(servers).where(eq(servers.id, id)).limit(1);
    const server = rows[0];
    if (!server) {
      return NextResponse.json({ error: 'Listing not found' }, { status: 404 });
    }
    if (server.ownerUserId !== userId) {
      return NextResponse.json({ error: 'You do not own this listing.' }, { status: 403 });
    }

    let processed: Buffer;
    try {
      processed = await processLogoUpload(await file.arrayBuffer());
    } catch (err) {
      if (err instanceof LogoValidationError) {
        return NextResponse.json({ error: err.message }, { status: 400 });
      }
      throw err;
    }

    const pendingKey = `pending/${id}.png`;
    await env.LOGOS.put(pendingKey, processed, { httpMetadata: { contentType: 'image/png' } });
    await db.update(servers).set({ pendingLogoKey: pendingKey }).where(eq(servers.id, id));

    const emailEnv = await getEmailEnv();
    if (emailEnv.adminEmail) {
      await sendNotificationEmail({
        to: emailEnv.adminEmail,
        heading: 'New pending logo',
        message: `${server.name} has a logo awaiting review.`,
        actionText: 'Review in admin',
        actionUrl: `${getAppUrl()}/admin`,
      });
    }

    return NextResponse.json({ success: true, message: 'Logo submitted for review.' });
  } catch (error) {
    console.error('Dashboard logo upload error:', error);
    return NextResponse.json({ error: 'Internal Server Error' }, { status: 500 });
  }
}
```

- [ ] **Step 1: Write the route**

```ts
import { NextResponse } from 'next/server';
import { getCloudflareContext } from '@opennextjs/cloudflare';

const ID_PATTERN = /^[a-z0-9-]+$/;

export async function GET(_req: Request, { params }: { params: Promise<{ id: string }> }) {
  const { id } = await params;
  if (!ID_PATTERN.test(id)) {
    return new NextResponse(null, { status: 404 });
  }

  let env: any;
  try {
    const ctx = await getCloudflareContext();
    env = ctx.env;
  } catch {
    return new NextResponse(null, { status: 404 });
  }
  if (!env?.LOGOS) {
    return new NextResponse(null, { status: 404 });
  }

  const object = await env.LOGOS.get(`live/${id}.png`);
  if (!object) {
    return new NextResponse(null, { status: 404 });
  }

  return new NextResponse(object.body, {
    headers: {
      'Content-Type': 'image/png',
      'Cache-Control': 'public, max-age=300',
    },
  });
}
```

import { getCloudflareContext } from '@opennextjs/cloudflare';
import { getAuthorizedAdminEmail } from '../../../../lib/accessAuth';

const PENDING_KEY_PATTERN = /^pending\/[a-z0-9-]+\.png$/;

export async function GET(req: Request) {
  if (!(await getAuthorizedAdminEmail(req.headers))) {
    return NextResponse.json({ error: 'Unauthorized.' }, { status: 401 });

      return;

    try {
      const formData = new FormData();
      formData.append('id', serverId);
      formData.append('logo', file);
      const res = await fetch('/api/dashboard/logo', { method: 'POST', body: formData });
      const data = (await res.json()) as { error?: string; message?: string };
      if (!res.ok) {
        throw new Error(data.error || 'Could not upload logo');
      }
      setServers((prev) =>
        prev.map((s) => (s.id === serverId ? { ...s, pendingLogoKey: 'pending' } : s))
      );
      toast.success('Logo submitted', { description: data.message || 'Awaiting review.' });
    } catch (err: any) {
      toast.error('Could not upload logo', { description: err?.message });
    } finally {
      setUploadingLogoId(null);
    }
  };

function ServerIcon({ name, logoUrl, size = 48 }: { name: string; logoUrl?: string | null; size?: number }) {
  const [imgFailed, setImgFailed] = useState(false);
  if (logoUrl && !imgFailed) {
    return (
      // eslint-disable-next-line @next/next/no-img-element
      <img
        src={logoUrl}
        alt=""
        width={size}
        height={size}
        style={{ borderRadius: size > 40 ? 12 : 10, flexShrink: 0, objectFit: 'cover' }}
        onError={() => setImgFailed(true)}
      />
    );
  }
  return (
    <div
      style={{
        width: size,
        height: size,
        borderRadius: size > 40 ? 12 : 10,
        background: getGradient(name),
        display: 'flex',
        alignItems: 'center',
        justifyContent: 'center',
        fontSize: size > 40 ? '1.5rem' : '1.1rem',
        fontWeight: 800,
        textTransform: 'uppercase',
        flexShrink: 0,
      }}
    >
      {name.charAt(0)}
    </div>
  );
}
